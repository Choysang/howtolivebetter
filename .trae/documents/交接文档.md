# 交接文档 · howtolivebetter 混合栈实施

写于 2026-10-03 · 交接自上一会话 · 下一代理开工前必读本文 + `AGENTS.md` + `docs/adr/0001-混合栈与零依赖.md`。

## 1. 目标（用户原话级别的需求）

把开源知识库《高性价比人生指南》（github.com/eternity4719/HowToLiveBetter，CC BY 4.0，34 章 654 条）按人生阶段重排成交互网站。核心思路一句话：**原书按主题写，人按阶段活**——同一句「现在最该做什么」，高中生和中年人的答案完全不同。

五大功能：
1. **五个阶段手册** `/stage/{id}/`：人工精选「先做 5 件」+ 按性价比排序的精华清单
2. **处境体检** `/checkup/`：苏格拉底式提问，匹配引擎全在浏览器本地计算，不上传任何数据
3. **紧急时刻页** `/scenario/{id}/`：被裁/被欠薪/租房/结婚/生孩子/确诊慢病/家人走了/被骗 8 个场景，按时间顺序给行动清单
4. **每日打卡** `/checkin/`：17 件零成本小事，免注册，数据只在设备
5. **630+ 条建议独立详情页** `/q/{uid}/`：证据等级 A/B/C、成本标签、文献链接、27→实际 65 条「争议」与 3 条「待核实」**原样保留不做删改**

用户特别要求：**上游会持续更新，必须轮询同步**——`npm run sync:watch` 已实现（ls-remote 比对 commit → 变化即 fetch + 自动重建）。

架构唯一事实源：根目录《howtolivebetter · 项目文档 v1（从零重写）.md》。技术栈经用户拍板为**混合栈**：管线/内核/编辑层零依赖 Node 24 + Astro/React 前端（偏差全部记录在 ADR 0001）。

## 4. 关键机制（改动前必知）

- **uid**：`uidFor(章号, NFC(标题))`，8 位 Crockford。`data/id-registry.jsonl` 现有 654 行 seen。上游改名：章内唯一孤儿自动续接旧 uid（追加 alias 行）；真碰撞直接构建失败。**别改 uid.ts 的哈希**——那是主键。
- **敏感隔离**：`sensitive` 条目不进精华榜、不进打卡、不进体检规则（rules.json），lite.json 带 `sensitive:true` 供前端展示标注；页脚常驻 12356 求助渠道（前端实现时别忘）。
- **manifest.counts 是唯一数字来源**：前端所有计数（条目数/证据分布/数据版本 commit 短哈希）从 manifest 读，文案禁手写数字。
- **隐私架构**：体检答案 → URL `#` 片段；打卡 → localStorage；**用户数据相关的岛源码禁止出现 fetch/XHR/sendBeacon**（M6 有静态断言测试）；全站网络出口收敛到 `frontend/web/src/lib/net.ts`（只允许同源 /kb/ 路径）。
- **知识包位置**：`frontend/web/public/kb/{hash}/*.json`（items/lite/chapters/stages/scenarios/rules/checkup/checkin/search-index/manifest）+ `public/kb/latest.json` 指针 + `public/llms.txt` 等。前端构建期直接 fs 读，岛运行期 fetch `/kb/{hash}/...`（hash 从构建期内联或 fetch latest.json）。
- **`ops/build.ts` 尚不存在**：package.json 的 `build` 与 sync --watch 都引用它（M6 第一件事）。
