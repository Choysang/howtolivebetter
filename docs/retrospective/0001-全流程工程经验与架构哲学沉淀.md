## 三、现代静态 SSG 部署与子路径适配（Subpath SSG Architecture）

在将 Astro 5 项目部署到 GitHub Pages（`https://username.github.io/repo-name/`）的过程中，遇到了两个经典且高频的现代 Web 陷阱，沉淀出标准解法：

### 1. 资源与知识包加载陷阱（“654 条建议全文索引加载不出”）
- **根本原因**：代码中使用静态相对路径 `/kb/latest.json` 发起 `fetch()`，浏览器会默认将其解析为根域名 `https://username.github.io/kb/latest.json`，在子路径仓库下直接返回 404；
- **自愈方案**：
  - 在全站唯一出口守卫 [`frontend/web/src/lib/net.ts`](file:///d:/zuomian/idea/gaoxingjiabirenshengzhinan/frontend/web/src/lib/net.ts) 中，动态读取 `import.meta.env.BASE_URL`，在发出请求前统一规范化补全子路径；
  - 既保障了本地开发（`/`）、自定义独立域名（`/`）下的无感运行，又保障了 GitHub Pages（`/howtolivebetter/`）下的零报错秒开。

### 2. 静态页面内部超链接陷阱（“点击跳转报 404”）
- **根本原因**：Astro 在构建时，默认不会对 HTML 模板中的硬编码字符串 `<a href="/stage/early/">` 进行自动重写，导致用户点击超链接直接跳转至根域名 404；
- **全自动后置规范化（`ops/build.ts`）**：
  - 在全量构建完成后，若检测到 `ASTRO_BASE` 环境变量，自动对 `dist/` 目录下全部 718 个 HTML 文件执行内部链接确定性正则替换；
  - 自动跳过协议相对路径（`//`）、外部 URL（`http:`）与已携带 base 的路径，彻底杜绝手动给全站上百处链接硬编码 base 的繁重与疏漏；
  - 配合 `404.astro` 智能子路径嗅探脚本，用户即使误访问根域名路径，也会被秒级静默自愈重定向回正确页面。

## 四、自然主义美学与物理触感交互（Aesthetics & Tactile Ergonomics）

1. **纸质书卷感与极客精密的平衡**：
   - 采用特种纸底色（`#f7f7f0`）与深林松针绿（`#12382d`），彻底消除纯黑白带来的数字眩光；
   - 运用 `-4°` 与 `+4°` 双层倾斜几何卡片甲板（`HeroCardDeck`），还原真实扑克牌与实体手账的层叠质感。
2. **空间解耦与视觉层级防御**：
   - **痛点**：右侧 3D 旋转卡片一度挡住了左侧单行大标题的文字；
   - **经验**：在首屏布局中，核心权威标题必须**独占顶层全宽居中空间**，与下方具有物理动效的卡片甲板在空间拓扑上实施上下分层解耦，杜绝横向栅格竞争空间。
3. **排版防折行铁律**：
   - 在高密度导航栏中，对关键药丸按钮严格施加 `white-space: nowrap !important; text-wrap: nowrap; flex-shrink: 0;`；
   - 将低频工具收纳为下拉面板（如 `🛠️ 更多工具 ▾`），配合媒体查询在大屏、中屏和移动端平滑过渡，确保无论屏幕分辨率如何变化，排版永远不产生难看的文字折行。
4. **程序化数学微音效**：
   - **100% 零音频文件依赖（0 MP3/WAV/AAC）**：通过纯原生 Web Audio API，基于 5200Hz 晶体滤波与双轨谐波合成点触、达成、待办、洗牌与胜利音效，网络体积为 0，触感即时无延迟。

## 五、Local-First 数据主权与极端可维护性（Data Sovereignty & Maintainability）

1. **物理级零外发隐私硬闸**：
   - 体检答案完全存放在 URL Hash (`#facts=...`) 中，符合 RFC 3986 物理层级不随 HTTP 请求出网卡；
   - 用户的日常打卡、个人宪法签署严格保存在端侧 `localStorage`；
   - 编写了 4 道自动化静态扫描测试（`ops/test/privacy.test.ts`），严格确保全仓除了只读守卫 `net.ts` 外绝对不存在任何 `fetch`、`XMLHttpRequest` 或上报原语。
2. **单向依赖架构与测试幂等闸**：
   - `frontend/web` ➔ `kernel` ➔ `contracts` 依赖严格单向，前后端完全零耦合；
   - `kernel/` 下所有核心函数纯函数化、零 I/O、单函数 ≤ 60 行；
   - 全套 96 项自动化测试覆盖形式化契约、纯函数数学推演与冒烟闸，1.1 秒内全绿执行，真正做到“完成 = 测试全绿，而不是感觉好了”。
