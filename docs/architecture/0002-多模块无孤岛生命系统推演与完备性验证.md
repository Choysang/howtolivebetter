## 二、纯函数内核与端侧数据流完备性验证

### 2.1 Local-First 端侧数据流全息模型

```
       ┌────────────────────────┐
       │     URL Hash 片段       │ ── 保护隐私：不进 HTTP 请求头，防服务端日志追踪
       │  (#facts=k1:v1,k2:v2)  │ ── 全息投影：复制链接即无损复原体检与匹配状态
       └────────────────────────┘
                   │
                   ▼ (只读解析与单向投影)
       ┌────────────────────────┐
       │   Atom 微状态响应式总线 │ ── React 19 useSyncExternalStore 工业级规范
       │  (lib/store.ts 内存态) │ ── 亚毫秒级跨微岛响应，零水合抖动
       └────────────────────────┘
                   │  ▲
    (广播变更同步) │  │ (window.addEventListener 'storage' / CustomEvent)
                   ▼  │
       ┌────────────────────────┐
       │      LocalStorage      │ ── 离散命名空间（htlb.checkin.*, htlb-my-constitution）
       │    (设备物理持久化)    │ ── 数据永不出端，物理级隐私隔离
       └────────────────────────┘
                   │
                   ▼ (受控只读单向导出)
       ┌────────────────────────┐
       │ 本地衍生文件 (.md, .ics)│ ── 零网络上传，纯客户端 Blob 下载
       └────────────────────────┘
```

#### 1. URL Hash 状态全息投影（State Holographic Projection）的形式化证明
- **隐私保护性（RFC 3986 保证）**：
  在客户端发起请求时，URI 格式规范严格规定 URI Fragment 不作为网络请求目标传导至服务端。即便全网部署代理或 CDN，服务端 Access Log 截获的永远只有纯净的路径（如 `/checkup/`），用户的健康、收入、负债隐私在物理层得到 100% 保障。
- **全息可再现性（Holographic Reproducibility）**：
  设用户事实空间为 $\mathcal{F}$，编码映射为 $E: \mathcal{F} \to \text{String}$，解码映射为 $D: \text{String} \to \mathcal{F}$。
  由于键值均为规范枚举，满足：
  $$\forall \mathbf{F} \in \mathcal{F}, \quad D(E(\mathbf{F})) = \mathbf{F}$$
  任何浏览器、任何设备在无 Cookie、无 LocalStorage 的绝对无状态环境下，只要加载带 Hash 的 URL，纯函数 `matchSituation(D(\text{Hash}), \mathcal{R})` 均能在 2 毫秒内原地重新推导出完全一致的匹配置信度分布。
- **注入防御验证**：
  CheckupWizard 中解码器强制过滤 `__proto__`, `constructor`, `prototype`，键名通过正则表达式 `/^[a-zA-Z0-9_-]+$/` 强校验，彻底杜绝对象原型链污染攻击。

#### 2. LocalStorage 的隔离命名空间与跨微岛广播完备性
- **离散键空间设计**：
  - `htlb.checkin.{YYYY-MM-DD}`：日度打卡流水，天然时间分片，避免单个大 JSON 随时间无限膨胀；
  - `htlb-my-constitution`：宪法 AST 规范存储，独立原子读写；
  - `scenario-progress-{id}`：场景进度，按场景隔离；
  - `htlb-read-items` / `htlb-fav-items`：全局条目状态。
- **双轨同步桥梁（Dual-Track Bridge）**：
  - 针对多标签页（Cross-Tab）：监听浏览器原生 `window.addEventListener('storage')`；
  - 针对单页面内 Astro 静态 HTML 与 React 孤岛（Cross-Island）：派发 `CustomEvent('htlb:storage-sync')`；
  - 针对 React 组件：通过 React 19 `useSyncExternalStore` 订阅，严格遵从规范（仅在 listener 触发时通知，不在 subscribe 阶段同步调度），保证 SSR 水合零报错、零跳帧。
