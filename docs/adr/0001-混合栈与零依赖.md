# ADR 0001 · 混合栈与零依赖（单会话 v1）

日期：2026-10-03 · 状态：已批准（用户选定）

## 背景

项目文档 v1 规定完整生产栈（pnpm/Turborepo + Zod 4 + Astro/React/Tailwind/shadcn + Hono/Cloudflare Workers/R2 + Playwright/fast-check），面向「4 天并行 Agent 上线」。本次为单会话交付，用户在三个选项（零依赖 / 全栈 / 混合）中选定**混合**：管线/内核/编辑层零依赖 Node 24，前端 Astro + React。

## 决策

1. **全仓 erasable TypeScript + 显式 `.ts` 导入**。Node 24 原生类型剥离直接执行管线；Vite/Astro 消费同一份源码。已验证 `node script.ts` 可行。禁用 enum/namespace/参数属性等不可剥离语法。
2. **根 package.json 零依赖**；唯一安装单元是 `frontend/web/`（astro、@astrojs/react、react、react-dom、tailwindcss、@tailwindcss/vite）。
3. **偏差清单**（不用什么、为什么）：

| 文档规定 | 采用 | 理由 |
| --- | --- | --- |
| Zod 4 | 手写严格校验器 contracts/kb.ts | 无 API 面；等价约束靠校验器+fixtures 黄金测试 |
| editorial YAML | ESM 纯数据 .ts | 零依赖、类型化；「纯数据」由 JSON 往返测试保证 |
| Turborepo/pnpm | 根零依赖 + 单安装单元 | 只有一个需安装的包 |
| Hono/Workers/R2 api | 纯静态 | 五大功能静态+本地计算即可满足；v1.1 再加 |
| shadcn/ui、React Compiler | Tailwind v4 + 手写组件 | 会话预算；组件源码同样在仓可改 |
| Playwright 隐私闸 | 静态断言 + net.ts 白名单 | 答案只进 hash，静态可证；运行时闸记 v1.1 |
| fast-check | 自写 mulberry32 + forAll | 属性测试照做，零依赖 |

4. **保留不变**：契约先行、kernel 纯函数零 I/O、uid 只追加注册表、三命名空间（source/overlay/derived）、构建期计算一切、隐私靠架构、机读面（llms.txt / items.json / 章节 .md 以 text/markdown）、页脚署名+数据版本、sensitive 不入榜不进打卡（挂 12356）、「每章必有阶段映射」测试、构建幂等硬闸。
5. **URL 按文档冻结**；另加 3 条旧路径重定向（/tools/assess→/checkup/、/tools/checkin→/checkin/、/moments→/）。

## 后果

- 构建在任何有 Node 24 的机器上秒级可跑（管线部分），前端构建需一次 npm install。
- 未来平移到 Workers/API：kernel 与管线零改动；前端模板已是静态 HTML。
